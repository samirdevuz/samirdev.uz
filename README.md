# samirdev.uz

Personal site of Samir Abdumo‘minov (samirdevuz), built with Vite, React and TypeScript.

## Edit content

All copy, links and projects live in `src/content.ts`.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build goes to `dist/`. Deployed on Vercel (see `vercel.json`).
